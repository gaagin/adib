# ADIB Online 1.1.64 — Pomodoro Sessions V2

Полный сервер и веб-интерфейс. Ограничения запросов Cost Control V3 сохранены. Пакеты Windows 1.1.62 и Android 2.5.70 не изменялись.

## Новое

- «Bitir»: завершение текущего Pomodoro досрочно с фактическим временем, без выполнения задачи.
- Каждый запуск — новый сеанс и полный выбранный интервал, по умолчанию 25 минут.
- Мини-окно: внутренняя область около 240×128; ↗/↙ меняет размер окна.
- История Pomodoro и рабочего таймера; сеансы в календаре ADIB, фильтры и приглушённое оформление завершённых.
- Постоянный журнал и очередь абсолютных записей Notion, повторы с backoff, защита от дубликатов.

## Установка

Содержимое `server` — корень проекта. Node >=22, `npm start`, `/api/health`. Сохраните .env, Railway Variables, аккаунты и постоянные данные. История требует **persistent volume и одной активной реплики**. Не удаляйте прежние файлы состояния. Подробная инструкция: `BROWSER-POMODORO-INSTALL-RU.txt`.

После redeploy `/version.json`: `queryFixBuild: 1.1.64-cost-control-v3-browser-sessions-v2`. Обновите вкладку Ctrl+F5. Основную вкладку держите открытой для плавающего окна.

История собирается с установки; прежние интервалы не выдумываются из суммарных значений. Существующая история рабочего таймера и показатели Notion сохраняются.
