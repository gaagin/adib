# ADIB Online 1.1.64 — Auto Countdown V4

Полный сервер и веб-интерфейс. Сеансы Pomodoro V2 и ограничения запросов Cost Control V3 сохранены. Пакеты Windows и Android не изменялись.

## Мини-окно

- Автоматически запрашивается по нажатию Start в онлайн-интерфейсе настольного браузера.
- Только отсчёт: шрифт подстраивается под высоту (32 px при 240×44), отступы 4 px, без названия и кнопок.
- Клик по времени раскрывает **это же большое плавающее окно**. Второй клик по большому времени сворачивает его.
- Измеренная внутренняя область локального Chromium — 240×44 px; минимум и внешние рамки контролирует браузер. **Скрыть верхнюю панель сайта в PiP нельзя.**
- Пока запуск подтверждается — «…». Блокировка PiP не отменяет таймер; ошибка самого запуска закрывает новое окно ожидания.
- Основную вкладку держите открытой. Новый сетевой опрос не добавлен.

## Установка

Содержимое `server` — корень проекта. Node >=22, `npm start`, `/api/health`. Сделайте резервную копию. Сохраните .env, Railway Variables, аккаунты и прежние данные. История требует **persistent volume и одной активной реплики**. Не удаляйте файлы состояния. Подробная инструкция: `BROWSER-POMODORO-INSTALL-RU.txt`.

После redeploy `/version.json`: `queryFixBuild: 1.1.64-cost-control-v3-auto-countdown-v4`. Обновите вкладку Ctrl+F5. Малый патч V4 требует установленной полной Auto Countdown V3; полный архив содержит все модули.
