# ADIB Online 1.1.64 — полный сервер с браузерным Pomodoro

Полный сервер и веб-интерфейс, не патч. Основа — 1.1.64 с ограничениями запросов Cost Control V3. Windows 1.1.62 и Android 2.5.70 не входят в пакет и не изменялись.

## Установка

- Сделайте резервную копию. Содержимое папки `server` — корень проекта/деплоя.
- Сохраните свою `.env`, переменные Railway, постоянные данные, аккаунты и тома. Не заменяйте их пустым примером.
- Node.js >=22; команда `npm start`; порт из `PORT`; healthcheck `/api/health`. Можно использовать приложенный Dockerfile.
- После redeploy `/version.json` должен показывать `queryFixBuild: 1.1.64-cost-control-v3-browser-pip-v1`. Обновите вкладку Ctrl+F5.

## Помидор в отдельном окне

Нажмите «Ayrı pəncərə» в Pomodoro личной задачи. Используется Document Picture-in-Picture в поддерживающем браузере на компьютере и HTTPS; иначе обычный popup без гарантии поверх всех окон. Основную вкладку держите открытой. Подробности, ограничения и проверка — в `BROWSER-POMODORO-INSTALL-RU.txt`.

## Ограничения запросов

Серверные кеши V3 сохранены; детали — `QUERY-FIX-INSTALL-RU.txt`. Окно отображает секунды локально, не запускает дополнительный сетевой polling. Команды и редкие проверки могут обращаться к Notion. Статистика HTTP Railway не равна количеству вызовов Notion.

## Проверка

`npm test`: 43 теста прошли; внешние сервисы подменены. Локальный Chromium проверен с тестовым адаптером, не с вашими рабочими базами. Отчёт — `TEST-REPORT.json`. Проверьте открытие, паузу/продолжение, переход работа/перерыв и синхронизацию на вашей выкладке перед отказом от Windows-приложения.
