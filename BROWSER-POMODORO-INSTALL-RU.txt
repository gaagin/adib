ADIB ONLINE 1.1.64 — AUTO COUNTDOWN V3 + POMODORO SESSIONS + COST CONTROL V3
Метка: 1.1.64-cost-control-v3-auto-countdown-v3

Изменён онлайн-сервер и веб-интерфейс. Пакеты Windows 1.1.62 и Android 2.5.70 не изменялись. Новые команды с сеансами включены для онлайн-интерфейса в настольном браузере; старые native/mobile команды сохранены.

КНОПКИ И СЕАНСЫ
Запуск автоматически открывает мини-окно. В большом плавающем виде «Bitir» — закончить текущий сеанс, в том числе досрочно. Задача от этого НЕ становится выполненной. Паузы в новом браузерном режиме нет: следующий запуск создаёт новый сеанс и полный интервал (25 минут по умолчанию, либо выбранная длительность).
Сохраняются задача, исполнитель из учётной записи, начало, конец и фактические секунды. При отключённых аккаунтах исполнитель отмечается как «İstifadəçi», имя не выдумывается.
Полные интервалы увеличивают счётчик полных Pomodoro. Досрочные сохраняются как отдельные сеансы и увеличивают только фактическое время. Время хранится без округления до целых минут; в Notion итог округляется до 0.001 минуты. После полного рабочего интервала доступен перерыв; после досрочного — новая работа. Перерыв не записывается как рабочий сеанс и не увеличивает рабочие минуты.
Существующие суммарные показатели Notion сохранены; старые интервалы не реконструируются из этих итогов. История Pomodoro начинает собираться после установки. Существующая история рабочего таймера сохраняется.

МИНИ-ОКНО V3 — АВТОМАТИЧЕСКИЙ ОТСЧЁТ
Нажмите «Başlat» в настольном браузерном интерфейсе ADIB: открывается маленькое плавающее окно. Внутри нет названия задачи, Bitir, статистики и кнопки раскрытия — только отсчёт, шрифт 14 px, без отступов.
Клик по отсчёту раскрывает ТО ЖЕ плавающее окно Pomodoro с названием, статистикой, завершением сеанса и историей. Оно не заменяется окном внутри основной вкладки. Второй клик по большому отсчёту сворачивает его обратно. Enter/Space также переключают размер. При следующем запуске автоматически возвращается мини-вид.
Браузер ограничивает минимальные размеры. Запрашивается минимальное окно; в локальном Chromium измеренная внутренняя область — 240×44 px. Внешняя рамка и панель сайта увеличивают общий размер; на Windows/другом браузере размеры могут отличаться.
АДРЕС / НАЗВАНИЕ САЙТА В ВЕРХНЕЙ ПАНЕЛИ PICTURE-IN-PICTURE СКРЫТЬ ИЗ СТРАНИЦЫ НЕЛЬЗЯ. Панель создаёт браузер для безопасности; стили ADIB её не изменяют. На изображении tiny.png показано только содержимое, не браузерная рамка.
Открытие PiP запрашивается в обработчике вашего нажатия Start до ожидания ответа сервера, иначе браузер теряет разрешение пользовательского действия. Пока сервер подтверждает запуск, в окне «…»; затем — время. Ошибка запуска закрывает новое окно ожидания. Блокировка самого PiP не отменяет запуск таймера: предупреждение показывается в основной странице.
Chrome/Edge, HTTPS, поддержка Document Picture-in-Picture. Без неё открывается обычный popup без гарантии «поверх всех окон». Фоновый запуск с другого устройства или автоматическое восстановление после перезагрузки не может самостоятельно открыть PiP без нового пользовательского действия.
Основную вкладку держите открытой. Закрытие маленького окна не завершает сеанс. Закрытие основной вкладки закрывает маленькое окно. Сон/закрытие браузера не обеспечивают непрерывные уведомления.

КАЛЕНДАРЬ ADIB
Рабочий таймер и Pomodoro показываются отдельными блоками по фактическому началу и концу. Поддерживаются день, неделя, месяц. Новые фильтры: тип сеанса, исполнитель, состояние и задача. Клик по сеансу открывает историю с выделением выбранного сеанса и переходом к задаче.
Завершённые сеансы обоих типов: приглушённый фон и серая рамка, без уменьшения читаемости текста. Активные — заметнее. Ожидающие подтверждения/синхронизации — отдельное обозначение.
Это календарь приложения ADIB, не создание отдельных страниц-сеансов в базе Notion. Журнал сеансов хранится на сервере; в Notion сохраняются существующие поля таймера и суммарные показатели.

ЗАПРОСЫ И СБОИ
Отрисовка секунд локальная. Нового сетевого интервала для маленького окна и истории нет. Существующий HTTP-опрос состояния раз в 5 секунд сохранён; при открытом маленьком окне допускается при скрытой основной вкладке. Частота зависит от фоновых ограничений браузера. HTTP к ADIB не означает вызов Notion на каждую секунду.
Все ограничения Cost Control V3 сохранены. Начальная загрузка, редкое обнаружение таймеров и команды могут обращаться к Notion. История не создаёт отдельную запись Notion на каждый тик.
Запуск/завершение сначала записываются в постоянный серверный файл. Если Notion недоступен, отображается ожидание синхронизации, а не ложное успешное сохранение в Notion. Неотправленный абсолютный итог повторяется с паузой 1–30 минут; очередь переживает перезапуск. Новый сеанс этой задачи не запускается, пока предыдущий итог не синхронизирован. Повторные команды защищены ID операций и сеансов; старое завершение не останавливает новый сеанс.

УСТАНОВКА
1. Сделайте резервную копию исходников, конфигурации и постоянных данных.
2. Полный архив: содержимое server — корень деплоя, включая все модули. Малый патч: замените все приложенные файлы в корне существующего полного онлайн-сервера 1.1.64; патч сам по себе не является полным сервером.
3. Не заменяйте .env, Railway Variables, аккаунты и данные пустыми примерами. Не удаляйте существующий файл состояния Pomodoro и work-sessions.json.
4. ОБЯЗАТЕЛЬНО используйте постоянный Railway volume для истории. По умолчанию Pomodoro сохраняется в /app/data/pomodoro-state.json при использовании Dockerfile. Если уже задан POMODORO_STATE_FILE, сохраните этот путь и убедитесь, что он расположен на volume. Перенос пути без переноса старого файла означает потерю видимости прежних данных.
   Рабочие сеансы хранятся в work-sessions.json рядом с файлом аккаунтов; сохраните существующий постоянный каталог. Используйте одну активную реплику сервера: журнал — файловый, без распределённой блокировки между репликами.
5. Node >=22, npm start, healthcheck /api/health. Redeploy, затем Ctrl+F5 в браузере.
6. /version.json должен содержать queryFixBuild: 1.1.64-cost-control-v3-auto-countdown-v3.
