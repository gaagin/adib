ADIB ONLINE 1.1.64 — COST CONTROL V3 + BROWSER POMODORO V1
Метка сборки: 1.1.64-cost-control-v3-browser-pip-v1

Изменён только онлайн-сервер и его веб-интерфейс. Пакеты Windows 1.1.62 и Android 2.5.70 не изменялись.

КАК ОТКРЫТЬ
1. Откройте онлайн ADIB по HTTPS в актуальном Chrome или Edge на компьютере.
2. Откройте Pomodoro нужной личной задачи. В заголовке появится «Ayrı pəncərə» (отдельное окно). Эта кнопка также есть в существующем плавающем блоке работающего Pomodoro.
3. Нажмите кнопку. При поддержке Document Picture-in-Picture браузер откроет отдельное окно поверх других окон.
4. «Pauza» — пауза, «Davam et» — продолжить, «Başlat» — запуск, «ADIB» — вернуться к задаче. Кнопка ↕ переключает компактный вид.
5. Закрытие маленького окна не ставит таймер на паузу. Держите основную вкладку ADIB и браузер открытыми. Закрытие/перезагрузка основной страницы закрывает маленькое окно; после загрузки откройте его снова.

Если браузер не поддерживает Document Picture-in-Picture, используется обычное всплывающее окно: разрешите pop-up для сайта. Оно НЕ гарантирует режим поверх всех окон. Ограничения браузера и ОС могут влиять на фоновую работу. Сон компьютера и закрытие браузера не обеспечивают непрерывные уведомления. Не удаляйте Windows-приложение до проверки в вашем браузере.

ЗАПРОСЫ
Отрисовка секунд использует существующее локальное состояние и сетевые часы ADIB. В модуле окна нет fetch и нет дополнительного сетевого интервала.
Существующая проверка состояния Pomodoro раз в 5 секунд остаётся одной; при открытом отдельном окне она разрешена и при скрытой основной вкладке. Это HTTP к серверу ADIB, а не прямой запрос к Notion на каждую секунду. Браузер может замедлять фоновые интервалы.
Серверные кеши и ограничения Cost Control V3 сохранены. Начальная загрузка, редкое обнаружение таймеров, пользовательские команды и сохранение итогов по-прежнему могут обращаться к Notion. Полного отсутствия расхода API и Railway не обещается.

УСТАНОВКА
Сначала сохраните резервную копию исходников и постоянных данных.
Полный архив: папка server содержит полный сервер и веб-интерфейс, а не только изменения. Корень деплоя — содержимое server. Node >=22, npm start, healthcheck /api/health.
Малый патч: только для существующего полного онлайн-сервера 1.1.64 с остальными модулями; содержит server.js, query-policy.js, read-cache.js, work-timer.js, ela-nov-paketleme-dynamic.html, browser-pomodoro.js. Замените эти файлы в корне сервера, рядом с package.json. Если состав старой установки неизвестен, используйте полный архив.
НЕ удаляйте и НЕ заменяйте .env, Railway Variables, аккаунты, volume и локальные данные. Пример .env.example не содержит ваших секретов.
Выполните redeploy. Откройте /version.json: queryFixBuild должен быть 1.1.64-cost-control-v3-browser-pip-v1. Обновите страницу Ctrl+F5.

ПРОВЕРЕНО
43 автоматических локальных теста: все прошли. Реальный HTTP-сервер — с подменёнными внешними сервисами; обращения к вашим базам не выполнялись.
Реальное открытие Document Picture-in-Picture в локальном headless Chromium: кнопка, заголовок, пауза/продолжение через тестовый адаптер, компактный вид, локальный тик и закрытие без команды остановки проверены.
Три визуальных состояния (обычное, компактное, узкое с длинным названием) проверены в Chromium: без переполнения и перекрытий.
Не проверено: ваша производственная выкладка, реальный таймер ваших задач/нескольких пользователей, поведение окна поверх приложений на вашей Windows и уведомления при сворачивании/сне. Приёмку выполните после установки.
