ADIB — редактируемое содержимое задачи / Notion page content

Исправлены: неявная label-обёртка вокруг панели кнопок и contenteditable, невидимая пустая область, отсутствие фокуса у нового блока, отсутствующие кнопки строк/столбцов у загруженной таблицы, повторное подключение paste-обработчика.

Теперь можно кликнуть в поле «Введите текст…» и вводить текст, добавлять заголовки, списки, чекбоксы, цитаты, код и таблицы. После добавления блока курсор находится в нём. Таблицы поддерживают добавление строк и столбцов. Жирный/курсив/подчёркивание применяются к выделению.

Сохранение: нажмите «Сохранить» внизу формы свойств. Содержимое отправляется pageBlocks через существующий /api/personal-task и записывается блоками Notion. В этой сессии настоящие пользовательские страницы Notion не менялись — браузерная проверка выполнялась на тестовых данных.

Для существующей задачи сначала загружаются блоки. При ошибке есть «Повторить»; сохранение до завершения загрузки блокируется, чтобы не заменить имеющееся содержимое пустыми блоками. Если закрыть редактор во время загрузки, ответ не запишется в закрытую форму.

Windows Portable 1.0.8 с предыдущими патчами:
1. Полностью выйдите из ADIB через трей → Выход.
2. Распакуйте ADIB-page-content-editor-update.zip в папку с ADIB.exe с заменой файлов.
3. Запустите ADIB. Data не удаляйте.
Патч меняет только resources/app/web/ela-nov-paketleme-dynamic.html. Предыдущие исправления интерфейса включены; исправленный main.js удержания Pomodoro поверх окон не перезаписывается.

Онлайн-сервис:
Разверните server-update.zip обычным способом, сохранив свой .env и серверное хранилище. Сервер в этой сессии не опубликован. Android APK не пересобирался.

Проверки: 113 серверных тестов прошли. В Chromium проверены ввод, все типы добавляемых блоков, фокус, жирное форматирование, pageBlocks при сохранении, редактирование загруженных таблиц и повторная загрузка после ошибки. Светлая/тёмная темы, пустое/заполненное поле и ошибка загрузки визуально проверены. Windows exe и физический Android не запускались.
