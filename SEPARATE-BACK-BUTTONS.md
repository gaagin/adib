# Независимые кнопки Назад — web v35 / Windows 1.0.2
Старая backHierarchy удалена. equipmentBackButton и personalBackButton — разные
DOM-узлы, обработчики и состояния доступности. В каждом режиме видна одна кнопка.
Планы: закрыть свойства/доску задач, затем перейти к непосредственному родителю,
без history.back(). Мои задачи: закрыть свойства/матрицу, перейти от подзадачи
к родительской задаче/контейнеру, подняться по контейнерам. Корневой уровень
Моих задач не переводит в оборудование и не меняет выбранный план.

на тестовых данных пройдены. Реальные записи Notion не изменялись.
