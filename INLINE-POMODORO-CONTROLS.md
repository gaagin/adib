ADIB 1.0.8 — управление Pomodoro прямо в списке
================================================
В списках Моих задач, задач оборудования/планов и контейнеров:
▶ Старт — новый рабочий помидор с сохранённой длительностью (обычно 25 минут).
▶ Продолжить — возобновить с оставшегося времени, без сброса сессии.
⏸ Пауза — приостановить активный помидор.
■ Стоп — завершить досрочно и зачесть отработанные минуты; не является сбросом.
Отработанные минуты рассчитывает существующая серверная логика, пауза не входит.
Статистика и таймер сохраняются. Кнопки не открывают свойства задачи/таймера.
Недоступные действия заблокированы. Повторный клик при сохранении не дублирует
команду. При сетевой ошибке остаётся последнее подтверждённое состояние и
появляется сообщение для повторной попытки. Кнопки не пересоздаются каждый тик:
сохраняется клавиатурный фокус. Карточки канбана сохраняют компактную статистику.

Windows: обновление с 1.0.7
--------------------------
1. Полностью выйдите через значок ADIB в трее → Выход.
2. Распакуйте ADIB-1.0.8-inline-pomodoro-update.zip в папку с ADIB.exe.
3. Подтвердите замену файлов, запустите снова. Data не удаляйте.
При более старой версии используйте полную сборку, сохранив свою Data.
Исправления мини-окна, запуска и единственного native Pomodoro не менялись.

Сервер/онлайн-версия
--------------------
Разверните новый server-update.zip в своём проекте сервера обычным способом.
Это полный серверный проект без приватных .env/токенов/данных. Существующий
.env и серверное хранилище Pomodoro сохраняйте. Добавлена одна серверная защита:
запоздалая/повторная пауза не может заново активировать завершённый/неактивный таймер.
Иначе расчёт статистики и общий API остаются прежними. Для онлайн-интерфейса
деплой обязателен. В этой сессии сервер не опубликован. Android APK не пересобран.
