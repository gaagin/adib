# Android 1.1.x: поле чата над клавиатурой

## Причина

В `OnlineMainActivity` на API 30+ используется edge-to-edge (`setDecorFitsSystemWindows(false)`). Корневой обработчик учитывал только status/navigation/cutout и возвращал `WindowInsets.CONSUMED`, игнорируя IME. WebView не уменьшался при открытии клавиатуры; `visualViewport` мог оставаться полноэкранным. Поэтому одного исправления JS/CSS недостаточно.

## Исправление

До поглощения insets задаётся нижний отступ корня `max(systemBars.bottom, ime.bottom)`, не их сумма. Это уменьшает реальную высоту WebView и позволяет существующему viewport-обработчику поднять composer. При закрытии клавиатуры отступ возвращается к системному. Высота navigation scrim остаётся высотой navigation bar; отрицательный margin соответствует полному отступу содержимого. API <30 сохраняет существующий adjustResize. Позиция верхней/боковых границ и вырезы не меняются.

Java-источник обновлён в `android-patches/mobile-camera-1.1.6/OnlineMainActivity.java`. Для smali-линии 1.1.11–1.1.13:

```sh
python3 android-patches/mobile-keyboard-insets/apply_keyboard_insets.py /path/to/apktool
python3 android-patches/mobile-keyboard-insets/test_keyboard_insets.py
```

Применять к полному **актуальному** Android-проекту со всеми более поздними правками (таймер, Gorulen isler и т.д.). Скрипт заменяет только известный метод отступов, идемпотентен, отказывается менять неизвестную версию. Не используйте старый базовый APK как готовое обновление.

## Проверка и доставка

Пять структурных/patch-тестов пройдены. Изменённый smali успешно собран Apktool 3.0.3 на полном снапшоте 1.1.11; это проверка сборки, **не готовый релиз 1.1.13**. На физическом Android-устройстве не проверено.

Это нативное изменение: Railway/reload сайта не обновляют установленную Activity. Нужен новый APK из актуальной Android-сборки, подписанный тем же сертификатом, что установленное приложение. Ключ подписи не хранить в репозитории. Без него нельзя выдавать новый APK за обновление существующего приложения.

На телефоне проверить: открытие/закрытие Gboard, многострочный текст, прикрепление изображения, поворот экрана, жестовая/трёхкнопочная навигация, светлая/тёмная тема. Поле ввода и отправка должны оставаться над клавиатурой; после её закрытия чат должен занимать прежнюю высоту.
