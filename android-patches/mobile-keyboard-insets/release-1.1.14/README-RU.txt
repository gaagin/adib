ADIB 1.1.14-cancel-preview — исправление клавиатуры

Собрано на базе вашего APK 1.1.13-work-note, versionCode 16.
Пакет com.adib.mobile.cancelpreview не менялся. Подпись совпадает с APK 1.1.13 из предыдущего архива: обновление preview не требует удаления приложения.
Это не обновление пакета com.adib.mobile.online. Если Android пишет о несовместимости подписи — не удаляйте приложение, сообщите об ошибке.

Исправление: в Android-оболочке учтена высота клавиатуры (IME) до поглощения системных отступов. Высота WebView уменьшается, чтобы поле ввода оставалось над клавиатурой. API ниже 30 сохраняет adjustResize.
Остальные файлы приложения, включая заметку Gorulen isler в окне сеанса, не менялись.

Установка: распакуйте ZIP, откройте APK, подтвердите обновление ADIB.
Проверено: сборка, подпись, выравнивание APK. На физическом телефоне не проверено.
