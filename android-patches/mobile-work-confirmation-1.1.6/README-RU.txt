ADIB Android 1.1.6 — кнопка отмены в нативном окне подтверждения рабочего времени.

Файл AdibWorkTimerOverlayService.java обновляет то же нативное окно, которое
показывается поверх приложения после остановки рабочего таймера. Добавляет
«Ləğv et» рядом с «Vaxtı təsdiqlə». Отмена подтверждается сервером; при ошибке
окно остаётся открытым и показывает сообщение.

В поле «Gorulen isler» можно добавить заметку о выполненной работе. При
подтверждении заметка дописывается в свойство задачи «Gorulen is» вместе с
диапазоном времени и именем сотрудника; ранее сохранённые записи сохраняются.
Чтобы это поле работало, сервер и Android-приложение должны быть обновлены.

Применение: замените в исходниках Android существующий
AdibWorkTimerOverlayService.java этим файлом (пакет класса —
com.adib.maintenance), затем пересоберите APK. Сохраните прежние applicationId,
versionCode/versionName и ключ подписи, чтобы установить обновление поверх текущего
приложения без удаления. Обновления веб-страницы недостаточно: это нативное окно,
поэтому без пересборки APK кнопка на телефоне не появится.

Этот патч не содержит ключей подписи. APK не собирался и на физическом устройстве
не проверялся.
