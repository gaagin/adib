ADIB — завершение задачи кружком в списке My Day/контейнера

Кружок слева теперь кнопка «Отметить выполненной». Нажатие отправляет PATCH /api/personal-task с status=Done и completed=true. Свойства задачи не открываются. После подтверждения сервера задача исчезает из списка незавершённых. Клик по названию/строке вне кнопок по-прежнему открывает свойства.

Во время сохранения повторные нажатия блокируются. При ошибке задача остаётся незавершённой, показано сообщение и можно повторить нажатие. Управление с клавиатуры работает как у обычной кнопки. Помидор автоматически не останавливается: этот патч меняет только статус задачи.

Windows Portable 1.0.8 с предыдущими патчами:
1. Полностью выйдите из ADIB через трей → Выход.
2. Распакуйте ADIB-task-circle-complete-update.zip в папку с ADIB.exe с заменой файлов.
3. Запустите ADIB. Data не удаляйте.
Изменяется только resources/app/web/ela-nov-paketleme-dynamic.html. Исправления канбана и компактного окна свойств включены. main.js не изменяется: патч удержания Pomodoro поверх других окон сохранится.

Онлайн-сервис:
Разверните server-update.zip обычным способом. Сохраните свои .env и серверное хранилище. В этой сессии сервер не публиковался. Android APK не пересобирался.

Проверки: 110 серверных тестов прошли; в Chromium проверены завершение, точный payload, защита от двойного клика, ошибка/повтор, управление клавиатурой и сохранение открытия свойств по названию. Светлая/тёмная темы, состояния сохранения/ошибки визуально проверены. Физический Windows и Android не запускались.
