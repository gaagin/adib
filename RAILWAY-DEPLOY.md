# ADIB — размещение на Railway

## 1. Подготовьте GitHub-репозиторий

Загрузите в репозиторий файлы проекта:

- `server.js`
- `package.json`
- `ela-nov-paketleme-dynamic.html`

Не загружайте `.env` и `node_modules`.

В `package.json` уже есть команда запуска:

```json
"start": "node server.js"
```

## 2. Создайте Railway-проект

1. Откройте https://railway.com/new
2. Войдите через GitHub.
3. Выберите **Deploy from GitHub repo**.
4. Выберите репозиторий ADIB.
5. Дождитесь завершения Deploy.

Если Railway не определит команду запуска автоматически, укажите:

```text
Start Command: npm start
```

Команду сборки можно оставить пустой или указать:

```text
npm install
```

## 3. Добавьте Variables

В сервисе откройте **Variables** и добавьте:

```env
NOTION_TOKEN=secret_...
PLAN_DATABASE_ID=...
MAKINA_DATABASE_ID=...
PLAN_DATA_SOURCE_ID=...
MAKINA_DATA_SOURCE_ID=...
TODO_DATABASE_ID=0ac3a96e-4687-4194-84cd-de563a12d85a
TODO_DATA_SOURCE_ID=b3d991ebc75b47ab8a88d2c723bc56db
GORULEN_ISLER_DATABASE_ID=02f39358-ebb4-4d32-b164-249f39ea2949
GORULEN_ISLER_DATA_SOURCE_ID=3136a23f839c40d3b6387de4d60af7f5
NOTION_VERSION=2025-09-03
CORS_ORIGIN=*
PUBLIC_APP_URL=https://adib-production-eba3.up.railway.app
LINK_SYNC_TTL_MS=900000
```

`PORT` вручную добавлять не нужно — Railway передаёт его приложению автоматически.

## 4. Создайте публичный адрес

После успешного Deploy:

1. Откройте сервис.
2. Перейдите в **Settings**.
3. Откройте **Networking**.
4. Нажмите **Generate Domain**.

Railway выдаст HTTPS-адрес вида:

```text
https://adib-production.up.railway.app
```

## 5. Проверка

Откройте публичный адрес в браузере. Также можно проверить API:

```text
https://ваш-домен.up.railway.app/api/plan-snapshot?full=1
```

Если вернулся JSON со снимком планов и машин, сервер работает.

## 6. Оптимизация расходов

В текущей версии ADIB уже включены меры для снижения использования Railway:

- автоматическая синхронизация по умолчанию выполняется раз в 5 минут, а не каждую минуту;
- синхронизация выполняется только когда вкладка ADIB открыта и видима;
- при возврате на вкладку выполняется обновление;
- неизменённый снимок не передаётся повторно благодаря ETag/ответу `304`;
- полная сверка с Notion выполняется раз в 2 часа, обычные проверки — инкрементальные;
- простой клик по объекту без перемещения не создаёт запись в Notion;
- ручная кнопка обновления по-прежнему доступна.

Если понадобится более частая синхронизация, можно добавить переменную фронтенда `PLAN_SYNC_INTERVAL_MS`. Минимальное значение ограничено одной минутой, например `60000`.

## 7. Стоимость

Railway предоставляет пробный кредит на ограниченный период. После его окончания бесплатный кредит ограничен и может быть недостаточен для постоянной работы сервиса. Для постоянной работы следите за разделом **Usage/Billing** и включите уведомления о расходах.

## Безопасность

- Не добавляйте `.env` в GitHub.
- Не вставляйте `NOTION_TOKEN` в HTML.
- Предоставьте Notion Integration доступ к базам Plan, Makina, ToDo и Gorulen isler.


## Ссылки на элементы

Добавьте `PUBLIC_APP_URL` с фактическим HTTPS-доменом Railway. При первом открытии приложения сервер автоматически заполнит новые свойства `ADIB link` в базах `Makina`, `ToDo` и `Gorulen isler`. Для повторной синхронизации вызовите `POST /api/sync-links`. Ссылки открывают соответствующий план, станок или задачу с масштабом 200%; ссылка на задачу также открывает редактор задачи.
