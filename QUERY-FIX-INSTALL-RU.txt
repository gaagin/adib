ADIB ONLINE 1.1.64 — QUERY POLICY V2

Основа: выбранный пользователем ADIB-Online-1.1.64-Compact-Design-Patch.zip. Дизайн, Windows и Android не изменены.

Причина недостаточности предыдущего патча: ограничивался лишь realtime-loader; прямые snapshot-запросы, включая refresh=1, могли миновать защиту. Теперь защита стоит на самих функциях snapshot/personalSnapshot.

УСТАНОВКА МАЛОГО ПАТЧА:
1. Сделайте резервную копию текущего server.js.
2. Скопируйте server.js и query-policy.js в папку сервера (рядом с package.json).
3. Выполните redeploy, не удаляя переменные Railway, .env, постоянный volume, аккаунты и локальные данные.

ПОЛНЫЙ АРХИВ:
Содержит все backend-модули и frontend-ассеты выбранной версии 1.1.64. Корень папки server — корень деплоя. Сохраните исходные переменные Railway и volume. Секреты и пользовательские данные в архив не входят. Требуется Node >=22, старт npm start. Не заменяйте свои секреты пустыми значениями .env.example.

ОБЯЗАТЕЛЬНАЯ ПРОВЕРКА ВЫКЛАДКИ:
Откройте /version.json: queryFixBuild должен быть 1.1.64-query-policy-v2.
Откройте /api/health: та же метка, externalSyncMs минимум 300000.
Если метки нет, запущены старые файлы/не тот каталог/не тот деплой; изменение частоты не вступило в силу.
queryMetrics.notionQueries считает логические запросы источников с начала процесса, а не все HTTP-запросы Railway и не внутренние повторные попытки rate gate. Сравните счётчик до/после минуты простоя после первой загрузки.

ПОВЕДЕНИЕ:
Фоновые сканирования — минимум раз в 5 минут. При повторных ручных refresh/force — один скан максимум в минуту, если кеш не инвалидирован записью. Записи задач и локальные realtime-обновления не задерживаются; после инвалидации допускается свежая загрузка. При сбоях применяется пауза 5–30 минут. Новые данные прямо из Notion могут появляться с задержкой до следующей проверки.
Пустой ответ 0 rows при delta-чтении — отсутствие найденных изменений, не удаление всей базы. Полная сверка раз в 2 часа остаётся.
Автоматическое сканирование/перезапись service links при просмотре оборудования отключено. Явный POST /api/sync-links сохранён; ADIB_AUTO_SYNC_LINKS=1 возвращает прежнее автоматическое поведение и дополнительные запросы.
В режиме TOKEN=native политика прежней частоты сохранена. Ограничение работает отдельно в каждой серверной реплике.

15 тестов прошли; производственная установка и браузерный запуск не выполнены. Результаты относятся к локальному серверу с изолированной имитацией внешних служб.
