ADIB — план дня, WIP и разбор задач (первая версия)

ДЛЯ КОГО
Обновление раздела «Мои задачи» в веб-сервисе и Windows Portable.
Новый интерфейс адаптирован также к узкому экрану браузера.
Нативный Android APK в этот выпуск не входит. Оборудование и его задачи
не включены в лимит WIP: он действует для базы «Мои задачи».

КАК НАЧАТЬ
В режиме «Мои задачи» нажмите «План дня» или «Разбор задач» слева внизу.
На большом экране плитка My Day также открывает новый план.
1. Выберите дату. Добавьте задачи вручную, отметьте одну кнопкой «Главная».
2. Укажите оценку каждой задачи в целых минутах.
3. По умолчанию допускается 4 задачи: главная и до 3 дополнительных.
   Бюджет — 120 минут. Превышение бюджета выделяется, задачи не удаляются.
4. «В работу» меняет статус задачи. Если уже 2 задачи в работе, появится
   предупреждение. Можно отменить или явно подтвердить превышение.
   Pomodoro остаётся отдельным таймером: его старт сам по себе не меняет статус.
5. «Выполнено» завершает задачу в Notion и освобождает место в плане.
6. В разборе доступны входящие, просроченные, давно без обновления и
   делегированные, для которых подошла дата проверки.
   «Позже» задаёт дату следующего разбора, не меняя дату задачи в Notion.
   «Делегировать» задаёт ответственного, статус Delegate и дату проверки.
   «Удалить» архивирует задачу в Notion после подтверждения.
7. В «Настройках» можно изменить лимит дня, WIP, бюджет и срок залеживания.
   По умолчанию залежавшаяся задача не обновлялась 14 дней.

ВАЖНО О ДАННЫХ
Первый план дня пуст намеренно: старые задачи в контейнере My Day не удаляются
и не переносятся автоматически. Выберите нужные задачи самостоятельно.
План хранится отдельно по каждой дате; автоматического переноса на завтра нет.
Планы, оценки и решения разбора сохраняются на вашем сервере в JSON-файле,
а не в новых свойствах базы Notion. Изменение схемы Notion не требуется.
Для другого устройства используйте тот же сервер и кнопку «Обновить».
Автоматической фоновой синхронизации открытого окна планирования пока нет.
При конфликте изменений обновите экран и повторите действие.
Настройки общие для текущего сервиса/рабочего пространства, не персональные
для разных пользователей. Требуется один экземпляр сервера с этим хранилищем.

УСТАНОВКА СЕРВЕРА
Сделайте резервную копию серверных файлов и постоянных данных.
Замените файлы приложения содержимым server-update.zip и перезапустите сервер.
Сохраните ваш .env, токены и прежние данные. Они в архив не включены.
Новые файлы task-management.js и task-management.test.js должны находиться
рядом с server.js. Дополнительных npm-зависимостей нет.

ПОСТОЯННОЕ ХРАНИЛИЩЕ — ОБЯЗАТЕЛЬНО ДЛЯ RAILWAY
Путь задаётся переменной TASK_MANAGEMENT_FILE.
Если она не задана, используется task-management.json в той же папке,
что и настроенный POMODORO_STATE_FILE; иначе папка data рядом с server.js.
Для Railway подключите persistent volume, например с точкой монтирования /data,
и установите TASK_MANAGEMENT_FILE=/data/task-management.json.
Убедитесь, что сервер может записывать файл. Включите файл в резервные копии.
Без постоянного тома планы и настройки могут потеряться при новом деплое.
Сначала обновите сервер, затем Windows. Старый сервер не имеет нового API.

УСТАНОВКА WINDOWS
Полностью закройте ADIB, включая значок в трее.
Распакуйте ADIB-task-management-update.zip в папку, где лежит ADIB.exe,
с заменой resources/app/web/ela-nov-paketleme-dynamic.html.
Не заменяйте папку Data. Нативный main.js этим архивом не изменяется:
исправления перемещения и поверх других окон Pomodoro сохраняются.
Запустите ADIB. При работе в браузере перезагрузите страницу после обновления сервера.

ПРОВЕРКИ
148 автоматических серверных/регрессионных тестов.
Браузерные сценарии на тестовом сервере: план, лимиты, бюджет, главная задача,
пауза разбора, делегирование, удаление с подтверждением, WIP и завершение.
Проверка интерфейса на ширине 1440 и 390 пикселей, светлая/тёмная темы.
Тесты использовали имитацию Notion, реальные задачи пользователя не менялись.
Обновление не развёрнуто в вашем Railway автоматически.
