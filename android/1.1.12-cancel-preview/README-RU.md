# ADIB Android cancellation preview — 1.1.13

Исходники-переопределения для отдельной установки на базе Android-снапшота 1.1.11. Текущая тестовая сборка: `1.1.13-cancel-preview`, versionCode 15.

Исправлена ошибка «Əməliyyat ID-si tələb olunur»: запрос отмены рабочего таймера включает обязательный `operationId` (UUID). Для отмены Pomodoro в привязанном к задаче сеансе отправляется `action=cancel`.

Примените файлы из `apktool/` поверх исходника 1.1.11 в `android/1.1.11-chat-order/`, соберите Apktool 3.0.3, выровняйте и подпишите своим ключом. Тестовый приватный ключ не публикуется.
