# ADIB Android 1.1.12-cancel-preview

Набор переопределений для отдельной установки на базе снапшота 1.1.11, с которым эта ветка была создана.

Файлы изменены в коммите `ac4d2b1fc1f54b5dea6c1c86f23acc7dd98824dc`. Исправление ошибки «Əməliyyat ID-si tələb olunur»: запрос отмены рабочего таймера теперь включает обязательный `operationId` (UUID).

Для сборки: скачайте исходник APK из `android/1.1.11-chat-order/`, замените файлы из этой папки, соберите Apktool 3.0.3, выполните zipalign и подпишите своим ключом. Тестовый ключ не публикуется.
