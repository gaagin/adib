# ADIB Android 1.1.12-cancel-preview

Это набор исходных файлов-переопределений для отдельной Android-установки с отменой рабочего таймера и Pomodoro. Базовый декомпилированный проект 1.1.11 (`apktool/`, `java/`, исходный архив) лежит в `android/1.1.11-chat-order/` на ветке `android-source-backups`.

## Изменения
- `AdibWorkTimerOverlayService`: добавлена кнопка `Ləğv et` в окно подтверждения остановленного рабочего таймера. Запрос `action=cancel` отправляется в API не в главном потоке; состояние ожидания очищается после успешного HTTP-ответа.
- `AdibFloatingTimerService`: для привязанного к задаче Pomodoro кнопка остановки теперь явно обозначена как отмена и отправляет `action=cancel`, а не `reset`.
- `AndroidManifest.xml`, `BuildConfig.smali`, `apktool.yml`: уникальный package ID `com.adib.mobile.cancelpreview`, версия `1.1.12-cancel-preview`, чтобы APK ставился рядом с основной копией.
- `AdibWorkTimerOverlayService$Cancel*.smali`: асинхронная отмена рабочего сеанса.

Для полной сборки сначала восстановите исходный архив 1.1.11 из `android/1.1.11-chat-order/`, затем замените одноимённые файлы этими. Сборка: Apktool 3.0.3 → zipalign → подпись собственным ключом. Подпись этого preview APK отличается от релизного сертификата; этот набор намеренно не содержит приватный ключ.

Проверены сборка, выравнивание и APK v2/v3-подпись. На физическом Android-устройстве не тестировалось.
