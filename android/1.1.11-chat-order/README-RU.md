# ADIB Android 1.1.11 — хронология чата

## Что исправлено

При срабатывании точного времени задачи приложение теперь пытается открыть карточку напоминания сразу, если телефон разблокирован. Удалена проверка внутреннего флага «ADIB на переднем плане»: она могла ошибочно отправлять только обычный системный баннер, даже когда ADIB был открыт.

В карточке сохранены действия «Отсрочка» и «Завершить» и переход к свойствам задачи свайпом вверх по верхней кромке.

## Важно для настройки Android

- В задаче должен быть включён флажок «Напомнить в дату задачи — уведомление и звук».
- Если Android не разрешит открыть Activity из фона, приложение использует системное уведомление; чтобы показать фирменную карточку поверх других приложений, в ADIB → «Напоминания и диагностика» включите «Окошко» и разрешите ADIB «Поверх других приложений».
- Для карточки на заблокированном экране отдельно включите «Окно на заблокированном экране» и выдайте ADIB системное разрешение полноэкранных уведомлений (на Android 14+). Android и прошивки Xiaomi/HyperOS могут дополнительно требовать автозапуск и режим батареи «Без ограничений».

## Сборка

Smali-проект `apktool/` — исходник для пересборки; `java/sources/` — декомпиляция JADX для чтения.

```sh
java -jar apktool_3.0.3.jar b apktool --aapt <path-to-aapt2> -o ADIB-unsigned.apk
zipalign -f -p 4 ADIB-unsigned.apk ADIB-aligned.apk
apksigner sign --ks <keystore> --ks-key-alias <alias> --out ADIB.apk ADIB-aligned.apk
```

APK подписан тем же сертификатом, что и предыдущая сборка 1.1.9. Проверены сборка, выравнивание и подпись. Физическое устройство в среде сборки недоступно, поэтому системные ограничения конкретного телефона проверить не удалось.


Полный ZIP исходников разделён на 11 Base64-фрагментов в `source-zip-parts/`, соберите их по порядку и проверьте SHA-256.
